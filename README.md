# Ares Xcode

**IDE berbasis web yang minimalis dan ringan untuk menulis kode tanpa gangguan.**

Ares Xcode adalah editor kode berbasis web yang dirancang dengan antarmuka sederhana dan berfokus pada pengalaman menulis kode. Seluruh kontrol dibuat seminimal mungkin agar pengguna dapat lebih fokus pada proses pengembangan.

Aplikasi ini berjalan langsung di browser tanpa memerlukan instalasi, akun, maupun backend.

## Fitur Utama

- **Code Editor:** Mendukung HTML, Tailwind, dan menggunakan CodeMirror 6 (kemungkinan memakai javascript).
- **Command Palette:** Mengakses berbagai perintah melalui satu pintu.
- **Live Preview:** Melihat hasil kode secara langsung.
- **Local Storage:** Menyimpan proyek secara otomatis menggunakan IndexedDB.
- **Theme:** Mendukung dark mode dan light mode.
- **Multilingual:** Tersedia dalam Bahasa Indonesia dan Inggris.
- **Responsive:** Mendukung desktop, tablet, dan ponsel.

## Teknologi

| Teknologi | Kegunaan |
|---|---|
| HTML | Struktur aplikasi |
| Tailwind CSS | Styling antarmuka |
| JavaScript | Logika aplikasi |
| CodeMirror 6 | Editor kode |
| IndexedDB | Penyimpanan lokal |

## Konsep

Ares Xcode mengusung konsep minimalis dengan editor sebagai fokus utama. Sebagian besar kontrol dan fitur tambahan hanya ditampilkan ketika dibutuhkan.
